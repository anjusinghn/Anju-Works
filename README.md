# Anju Works

Anju Singh’s portfolio at [anjusingh.space](https://anjusingh.space). It uses the Next.js source from [Rishi Vhavle’s portfolio](https://www.rishivhavle.works/) with Anju’s work, a garden background outside the content frame, and the same animated layouts.

```sh
npm ci
npm run dev
npm run build
```

The site data lives in `config/`. The résumé is at `public/anju-singh-resume.pdf`. The contribution calendar uses a dated public GitHub snapshot in `config/sample/`, or the GitHub API when configured with `GITHUB_TOKEN`.

The layout and reusable components derive from the MIT-licensed source of [Aditya Ojha](https://github.com/AdityaKodez/adityaojha). See [LICENSE](LICENSE).
